Work & Project Reports

Four written deliverables from 2023, produced on the desktop GIS stack rather than in code. Each was handed to a team on a training basis, so the brief was to solve the problem and then show how it was solved. That is why the pages carry full parameter dialogs and intermediate screens rather than only the final map. Terrain and building extraction from LiDAR, point cloud filtering and object classification, LoD2 city modelling against footprints, and a multi criteria siting study for Łódź.

These were written to be followed, not only read, which is what a walkthrough deliverable has to do. They sit alongside the code case studies rather than replacing them. The reports show the production tooling a GIS team actually runs on, ArcGIS Pro, TerraScan, TerraSolid, CloudCompare and PDAL. The case studies show the same class of problem solved in Python, with the numbers measured rather than inspected by eye.
